# Workspace scope

Work only on the root Laravel/Inertia application in this repository. The
`symfony-api/` directory is a separate application and must not be changed
unless the user explicitly asks for Symfony work.

# Code style

- Keep source-code lines at 120 characters or fewer, including PHP, JavaScript/JSX, YAML, tests, and
  agent-authored comments or documentation.
- Prefer readable multiline arrays, method chains, function arguments, JSX props, and JSX children over
  dense one-line code.
- Before finishing, scan every changed text file for lines over 120 characters and reformat any violations
  without changing behavior.
